# DolarCalc

Con este proyecto, además de poder brindar una herramienta simple para las operaciones de compra y venta de dolares, he aprovechado para aprender sobre **AlpineJs** (https://alpinejs.dev/) y sobre **Tailwindcss** (https://tailwindcss.com/).

## Fuente de datos

Los diferentes datos para la conversion de moneda los obtengo desde DolarApi.com (https://dolarapi.com/docs/argentina/)
